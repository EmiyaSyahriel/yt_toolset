# yt_toolset
Personal automation utility set for my own YouTube videos, might not suit everyone.

Made using V.

## Usage
`ytts [subtool] [subtool args...]`

## Build
### Prerequisites
- V ( tested on 0.5.0 )
- C compiler ( tcc, gcc, clang )
- Git

### Build
```bash
git clone https://gitea.emiyasyahriel.my.id/EmiyaSyahriel/yt_toolset
cd yt_toolset
chmod +x ./build.vsh
./build.vsh build
./build.vsh install
```
> For GitHub, clone `https://github.com/EmiyaSyahriel/yt_toolset` instead
